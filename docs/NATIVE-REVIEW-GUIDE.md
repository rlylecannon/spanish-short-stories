# Native-speaker review: guide for the reviewer

**What to review:** `new-stories/c12/NATIVE-REVIEW.md` lists every flagged item for the 20 C1/C2 stories (regional vocabulary, Garífuna, Palenquero, Guaraní, Creole lines, legal and factual claims). Also skim the A1–B2 stories for regional wording.

**How to mark each item:** OK / change to "…" / remove. Add a short reason for any change.

**Reviewer profile:** native or near-native Spanish; ideally one reader from Central America/Caribbean and one from Mexico or the Andes. A subject expert is needed for legal and historical claims, and community speakers for Garífuna, Palenquero, Guaraní and Creole lines.

**Return format:** a copy of NATIVE-REVIEW.md with your marks. Send it back and the changes go in as one batch.

**Audio:** `docs/audio-recording-script-A1-A2.csv` lists all A1–A2 story lines with the exact file name each recording needs (`<story>/<line>.mp3`). Host the files and set `audioBase` in `site-config.json` (see `docs/AI-BACKEND.md`).
